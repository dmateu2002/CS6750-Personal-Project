# Better Prompt (Reusable)

Use this prompt when you want an AI coding agent to build or update your promo site:

```text
I have an iOS app called Momentum and the domain mntm.io.

Build a highly creative, premium marketing website in a new `website/` folder without breaking my existing app code.

Requirements:
1. Keep app and website separated (do not move existing iOS files unless necessary).
2. Include all essential sections: hero, value proposition, features, pricing, FAQ, footer.
3. Pricing must clearly show: Free.
4. Add App Store CTA buttons and centralize the App Store URL in one editable place.
5. Use a bold visual style (not generic templates), with strong typography, motion, and responsive design.
6. Match Momentum's brand feel: tactical, focused, consistency-driven.
7. Add `website/GEMINI.md` with clear maintenance instructions.
8. Add `website/WHAT_I_BUILT.md` explaining exactly what you changed and how to maintain it.
9. Add `website/BETTER_PROMPT.md` with an improved version of my prompt for future reuse.
10. After implementation, provide a concise summary with file paths and exact next steps.

Important:
- Make concrete edits directly in files.
- Do not just propose ideas.
- Ensure the site works on desktop and mobile.
```
